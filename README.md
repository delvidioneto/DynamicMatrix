# Dynamic KPI Matrix

Custom visual Power BI — matriz dinâmica de KPIs com células multi-informação.

O código-fonte e o pacote estão em [`dynamicKpiMatrix/`](dynamicKpiMatrix/).

## Início rápido

```bash
cd dynamicKpiMatrix
npm install
npm test
npm run package
```

Pacote gerado: `dynamicKpiMatrix/dist/dynamicKpiMatrix*.pbiviz`

Documentação completa: [dynamicKpiMatrix/README.md](dynamicKpiMatrix/README.md)
